    recording · Super+Shift+R

    The game, the chat and your mic, each on its own track

    The audio panel picks what goes in: the GoXLR's channels or, without one, the default output and mic, each with its own level. Every channel is also recorded on its own, so the editor has a row for each. Cut, take pieces out, blur names, drop pictures in. Export writes a new file and leaves the recording alone.

    settings · Super+,

    Every setting in one window

    Theme, layout, lock, the launcher, games, sound, modules and system. What you change lands in ~/.config/frameshell/shell.json, only the values that differ; default takes one back. Anything that needs sudo opens in a terminal.

    infinite canvas · Super+wheel

    A desktop without edges

    With the canvas layout, windows float on one plane and the screen is a view you move over it. Super+wheel zooms out until every window is in view, each one a live preview; a click goes there. The bar shows a minimap instead of workspace numbers. Hyprland's tiling is still there: frame layout tiling.

    game mode: on, a game runs

    • animations and blur off
    • power profile: performance
    • popups quiet; calls and alarms still come through

    • a GoXLR profile for playing, if you set one

    When the last game closes, everything goes back. Steam games, gamescope and your own window classes count.

    frame install

    One line to install, and only what you tick

    The setup asks how much you want, ticks the apps off a checklist, then the layout and the theme. Only the modules you pick are downloaded; frame add brings more later. Long steps run behind a spinner and log to a file. frame alone opens a menu: update, theme, layout, remove, status, clean.

    A hung shell looks like a frozen PC. The watchdog asks it every 5 seconds, replaces it after three missed answers and takes the lock over again if the session was locked. SuperShiftEsc does it at once.

    • a bar on every screen: workspaces or the canvas minimap, clock, media, stats, updates, the recording dot

    status · work in progress

    frameshell is a work in progress and still has a lot of bugs. It runs on my CachyOS machine; on yours, expect things to break. TESTING.md lists what to try and the command that shows why when something fails. Ideas and bugs go on the board.
