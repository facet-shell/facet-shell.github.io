A desktop for CachyOS and Hyprland, in two styles and six themes

facet is a Quickshell desktop with the same colors in every app. The style sets the shape of things, the theme sets the colors, and you can switch both at any time. Try it below.

curl -fsSL https://facet-shell.github.io/install.sh | bash

It asks what you want and fetches only that. Work in progress: it runs on my machine and still has bugs.

The same features in both styles

A style only changes how things look. What the desktop can do stays the same.

launcher

One box for apps, Claude, Discord, Spotify, web search, files, timers, the clipboard, commands and wallpapers.

Super+Space

notifications

Rules per kind: what pops up, what stays quiet, what keeps ringing until you answer.

discord · steam · spotify

Calls, messages and voice joins, Steam invites and what is playing show up in the shell. A voice overlay shows who is talking.

sound

GoXLR faders and an app mixer in the control center. Move a fader on the GoXLR and it moves on screen.

Super+C

games

A task manager, and a game mode that turns on when a game starts. Popups shrink to small see-through pills.

windows

Tiling with workspaces, or an infinite canvas where windows sit on an endless plane you can zoom out of.

capture

Screenshots, screen recording with an editor, and drawing right on the desktop.

Print · Super+Shift+R

lock to boot

Lockscreen, login screen, boot splash and GRUB, all in the same theme.

Super+L

apps

Ghostty, fish, Discord (Vesktop), Spotify, Steam, Zed, Zen and Dolphin in the same colors as the shell.

Styles and themes

The style is the shape, the theme is the colors. Each command switches the whole desktop, the apps included.

Install

For Arch and CachyOS with Hyprland. One line gets the facet command and starts its setup.

curl -fsSL https://facet-shell.github.io/install.sh | bash
  • It asks for the full desktop or just the shell, then the apps one by one, the layout and the theme.
  • Only what you pick is downloaded. Every part is its own repo.
  • Your old configs are backed up first, and facet restore brings them back.
  • Coming from frameshell? migrate-to-facet moves an install over once.
