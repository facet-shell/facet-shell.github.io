A desktop for CachyOS and Hyprland

My Quickshell desktop. Discord, Steam, Spotify and the GoXLR are built in, and every app wears the same colors. It comes in styles: tui and bloom so far, switch them at the top.

curl -fsSL https://facet-shell.github.io/install.sh | bash

A hobby project. It runs on my machine and still has bugs.

Everything on it works, the bar too.

launcher Super+Space

One box for everything

Apps, Spotify, Discord, timers, emoji, files, the clipboard, the web, and Claude if you have it. A prefix picks the mode.

dashboard bloom only

The day at a glance

Weather, music, the month, your GitHub and what's eating the CPU. It drops out under the clock.

control center Super+C

Toggles, sound and every app's volume

With a GoXLR the faders follow the hardware. Move one and you see it here.

game mode

Start a game and the desktop steps back

Game mode turns on by itself. Popups shrink to one line, and whatever can wait, waits.

Drag the voice overlay. Song changes and friends coming online wait until you quit.

lockscreen Super+L

Locked behind a blur

It locks and unlocks by itself here. Click it and type anything. The login screen looks the same.

Any password works.

infinite canvas Super+wheel

A desktop without edges

Windows on one endless plane, and your screens are views onto it. Drag around, zoom out, click a window.

Ctrl+wheel zooms in here too.

Install

curl -fsSL https://facet-shell.github.io/install.sh | bash

For Arch and CachyOS with Hyprland. It asks what you want and only fetches that. Your old configs get backed up first. Coming from frameshell? Use migrate-to-facet.

facet
a menu of the everyday stuff
facet style bloom
switch the look
facet theme set nebula
switch the colors
facet add steam
add a part later
facet update
pull and apply everything
